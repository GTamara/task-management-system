## Установка:

`npm run install:all`
----
## Запуск проекта:

В директории корня проекта:
`npm run dev`
----
## Форматирование кода

Проект использует автоматическое форматирование при коммите.

Что форматируется при коммите:
* TypeScript файлы → ESLint

* HTML шаблоны → ESLint + Prettier (атрибуты на новых строках)

* SCSS файлы → Stylelint
