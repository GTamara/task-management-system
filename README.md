## Установка:

`npm run install:all`
----
## Запуск проекта:

В директории корня проекта:
`npm run dev`
----
## Форматирование кода

Проект использует автоматическое форматирование при коммите.

Что форматируется при коммите:
* TypeScript файлы → ESLint

* HTML шаблоны → ESLint + Prettier (атрибуты на новых строках)

* SCSS файлы → Stylelint

## 🛠️ Технический стек

* Angular 19 + TypeScript 5+
* Angular Material 3.0 с дефолтной темой "cyan-orange"
* NgRx ComponentStore для state management
* Standalone компоненты и lazy loading
